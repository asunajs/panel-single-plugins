# panel-requests —— 给面板仓的反向需求

这里是**面板宿主的能力补齐需求**，不属于任何插件：

| 文件 | 给谁 |
| --- | --- |
| `PANEL-TODOS.md` | 需求清单：每条带现状/提议/验收判据（含已作废条目的记录） |
| `PANEL-SESSION-PROMPT.md` | 直接粘给面板仓工作会话的提示词（行号已对源码核实） |

背景：插件（如 `yangshipin/`）因宿主能力缺口做了临时兼容（引擎分支、静默吞错）。
这些 workaround 的根因都在面板侧 —— 补齐后插件代码可以整体删掉对应分支。

⚠ 插件目录里**不保留**面板向内容：插件 = 面向用户的产物；
宿主诉求 = 给面板维护者的工单。两类读者，两个目录。
